# 真实操作录屏

文件：`walkthrough.mp4`，171.44秒（2分51秒），1440×1000、25fps、4286帧、H.264/AAC。文件校验与动作时间记录见 `recording_validation.json`。

录制方式：Playwright实际操作Chrome，FFmpeg连续采集Xvfb桌面和独立PulseAudio浏览器播放声音。没有剪接或倍速，没有替换配音；录到的声音来自样例原片/成片，未录制麦克风解说。保留完整渲染等待（首次约16秒）。

音频按采集设备时间戳归整，视频码流逐字节保持不变；码流hash已核对。录屏第18秒、110秒的画面源时间与原片音频相关性抽查差约10.5ms、35.1ms。此为同步检查，不代替人工逐字听审或真人自然度验证。

| 约略时间 | 实际操作 |
|---|---|
| 0–14秒 | 开始页、合成来源、打开样例 |
| 14–28秒 | 原片有声播放、VTT字幕、文字定位 |
| 28–42秒 | s03/s04/s05必留，30秒目标冲突，再调回90秒 |
| 42–61秒 | 获取规则建议、查看理由并应用；真实建议仍超目标 |
| 61–87秒 | 人工删除次要内容，恢复一段再撤销 |
| 87–104秒 | 提交渲染并完整保留等待 |
| 104–125秒 | 播放77.988秒实际成片，两处切口与字幕 |
| 125–136秒 | 实际下载MP4、SRT和删减记录 |
| 136–148秒 | 恢复片段，查看上一版并验证不可下载 |
| 148–171秒 | 撤销恢复、再次实际渲染，播放最终成片 |

`walkthrough_download.mp4`、`walkthrough_download.srt`、`walkthrough_download_record.json`为录像中的实际下载，哈希再次核对一致。录屏本身不包含人为注入失败；失败与重试由独立浏览器验收和browser_failure.png证明。

真实截图为browser_*.png；recording_source.png、recording_result.png、recording_stale.png从本次录屏抽帧。全部保留在本地deliverables，不作为Git大文件提交。
