# 补录上限60秒（2026-11-07）

每句直接录音与上传补录统一支持最长60秒。直接录音到60秒自动结束，上传超过60秒时后端拒绝。沿用原来的试听、识别、确认替换和导出流程。

长于原句的补录完整保留声音，画面在原句结束后停留于该句末帧；不取用下一句画面或声音。短于原句仍补尾部静音。若保留背景音，原句结束后的延长部分补背景静音。预计时长、必留时长、字幕和后续片段位置一同调整；恢复原声后回到原时长。补录词位置的试听定位到补录音轨。

新增确定性媒体回归用3秒/60秒录音替换2秒原句，逐帧检查末帧延长、末尾声音、字幕顺延、长录音中的剪词、必留时长与原声恢复。60.1秒负例在识别前拒绝。推理采用测试替身，媒体/FFmpeg实际执行。

另用浏览器真实MediaRecorder录满一分钟并自动停止，接入实际本地ASR、确认替换和MP4下载；麦克风输入来自授权样例的测试设备，不代表真人录音品质或物理设备验收。记录见browser_validation.json。

原片坐标保持不变。补录跨度的sourceStartFrame/sourceEndFrame延续现有音轨编辑坐标；新增recordingVideoStartFrame/recordingVideoEndFrame明确原句画面区间，渲染时按音轨偏移播放对应画面，越过原句的部分重复末帧。输出按30fps重新建立连续时间戳。
