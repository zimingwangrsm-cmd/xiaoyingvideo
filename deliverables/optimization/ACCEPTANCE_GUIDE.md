# 本轮验收操作

1. 保持SSH转发终端开着：`ssh -N -L 8767:127.0.0.1:8767 用户名@服务器地址`，浏览器打开 `http://localhost:8767`。只有8767需要转发。
2. 先打开 `/delivery`。左侧是128.2秒真人原片，右侧是25.2秒AI任务粗剪；先后播放，避免两段同时出声。目标是语言背景简介，省略的家庭工作/书店支线并非在所有任务中都无价值。
3. 回到工作台，选择“AI精简示例：语言背景一分钟简介”。检查60秒上限、两段必留和“这次保留的主线”。该主线可修改保存；改主线可能产生不同的合理删减。
4. 点击生成建议，等待本机CPU推理。本例实测约200秒。检查每项原文、删除理由、预计时长；可接受一项、拒绝一项或全部接受剩余项。依赖句合成同一项，避免只删前提留下“这里”等指代。
5. 任一段打开“精修 / 补录”。文字校对、剪辑、声音分组；同时输入字幕和备注，只保存字幕，备注应保持且标注未保存。关闭抽屉按Esc，焦点返回原按钮；页内切项目草稿隔离。刷新/关闭仍需保存或接受放弃提示。
6. 按词剪辑前先选“剪辑”，只可用实测时间戳。整段字幕改字只改变字幕，不能使声音说出新词；已有整段校对需先恢复原字幕，才能剪词。词级校对后可剪词。
7. 如需补录，选“声音”，上传本人授权WAV/MP3/M4A；查看确认卡片段ID、原文、文件名、时长与保留背景参数，试听后确认。过长录音拒绝；短录音补尾部静音，画面时长不变，口型不同步。保留BGM需先分离，分离可能退化。现有自动化补录用授权原片摘录，只证明工程流程。
8. 生成短片。结果页选择切口，点击“循环试听前后”，检查实际渲染片段切点前1秒、后1.5秒，再停止。检查人名、地名、否定、数字和条件；最后下载MP4、SRT和记录。
9. 高级工具重新识别前显示重置影响；确认后可选历史识别版本恢复。恢复会生成新revision，需重新渲染，不能直接下载旧版当新成果。

本轮手机模拟已走完整任务，但实机软键盘、真人新录音、作者认可和切口自然度仍需要验收者完成。不要以测试数量代替作品质量判断。

故障时先刷新健康接口 `/api/health`；端口冲突或服务未启动，按README_V2启动。故障注入只用于隔离测试，正式8767入口关闭。
