# 真实AI精简示例：语言背景简介

本例为任务导向粗剪：把包含语言背景、家庭成员工作、书店活动与邀约的完整分享，整理成一分钟以内的语言背景简介。

| 指标 | 实测结果 |
|---|---|
| 真人原片 | 128.200秒 |
| 成片 | 25.188秒 |
| 时长减少 | 80.35% |
| 保留内容 | 5个完整片段 |
| 操作来源 | 本地Qwen评估相关性＋实际帧预算选择；全部接受候选，没有人工追加删除 |
| 模型耗时 | 199.9秒（CPU，包含结构化评分与前后依赖判断） |

## 明确的编辑目标

一分钟个人语言背景简介。保留云南来源、泰国出生、八岁移居台湾的完整时间线与一句结束语；整组省略家庭成员工作、书店活动、地址和邀约，避免“这里”“还有”等失去前提。可以短于60秒，不必填满。

这是演示者给定的编辑任务，不是模型自动证明了“哪些话没有价值”。家庭和书店内容是本任务中的支线；同一素材换一个主线可能得到不同选择。目标是上限，不强行凑满60秒。

## 保留内容对照

- s01：大家好,现在我要用云南话来看给大家听。
- s02：我叫做朱导。
- s03：我是在泰国清迈出生的,算是华人。
- s08：我住到八岁的时候就是跟我爸我妈就搬到台湾来住了。
- s37：再见。

以上为自动识别文字，仍有专名和口音误识别，例如人名需要本人确认。文本层已检查“开场／语言、出生地、迁居、结束语”的顺序；未声称作者已盲听同意或已完成专业字幕审校。
